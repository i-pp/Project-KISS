## Apply the header to cleared material

Use [the approved C-style header](KOL-v1-source-header.h.txt) only for material
whose rightsholder has authorized KOL application. Its I-plusplus copyright
line is appropriate only when that ownership is accurate. Preserve every
applicable original copyright, attribution, and license notice. Use comment
syntax supported by the file format; use an accompanying, exact-path notice
when a file cannot carry comments.

When distributing covered material, include the complete LICENSE and applicable
NOTICE information. Identify distributed changes as required by section 4(c).
Do not treat adding a header as permission to relicense someone else's work.

## AceIS attribution in NOTICE

For a distribution that actually includes covered AceIS material, the applicable
NOTICE attribution is:

> This distribution includes AceIS, developed by I-plusplus and the AceIS
> contributors.

Preserve that attribution under section 4(d) where it applies to included
material. Project-KISS currently distributes licensing documentation, not an
AceIS implementation. Its root NOTICE describes that narrower scope rather
than claiming that software is included.

A NOTICE supplies attribution information and cannot add license conditions.
Credit in an About screen or manual is optional. No credit is required solely
because a covered compiler or tool produces output; copied or embedded covered
material remains subject to its applicable terms.
